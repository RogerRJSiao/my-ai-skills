## Power BI 財務/會計檔案模板

- 檔案位置：OO知識中心 > Power BI > BI Report > Financial & Accounting

- 命名規則：`三角與非三角合併v{主版號}.{次版號}_{欄位模式}.pbix`
    - 主版號：反映資料模型結構、參數機制等。
    - 次版號：反映 SQL 優化、欄位增減、bug 修正等。
    - 欄位模式
        - 「full」是 taxdbar、taxdbar_tri 合併後的 47 欄位，延續自 v2、v3 的原有功能。(latest: `v3.1_full`)
        - 「finance」是向財務 chc 張課長詢問，需求確認後保留指定的 27 欄位。(latest: `v3.1_finance`)

- 釋出版本
    | 版本 | 上線日 | 功能說明 (重要改動) | 其他備註 |
    | --- | --- | --- | --- |
    | **v1** 		| 2025-08-06 | 連線 PostgreSQL DB，只從 taxdbar 取出 75 欄位資料。 | 原檔名：TAX450-財務.營業-20250806-只有TAX450不含成本.pbix |
    | **v2**		| 2025-11-28 | 連線 PostgreSQL DB，同時從 taxdbar、taxdbar_tri 取出 47 欄位資料。 | 根據當時財務與營業單位討論，因欄位重複或不需要，故欄位數由 75 縮減為 47 個。 |
    | **v3** 		| 2026-04-14 | 加入編輯參數欄位 (起迄月結年月、公司別)。<br>Direct Query 先載入所有年月、所有子公司資料，再用 PQ 從資料集篩選成子集。 | -- |
    | **v3.1_full** 	| 2026-08-20 | SQL 查詢優化 (用索引建查詢，47 欄位)。<br>Direct Query 只載入指定範圍的年月、子公司資料。 | v3.1 新增 full/finance 欄位模式分支，但因底層資料模型與參數機制 (年月、公司別) 未變動，故仍歸類為次版號改動。 |
    | **v3.1_finance** 	| 2026-08-20 | SQL 查詢優化 (用索引建查詢，27 欄位)。<br>基於 v3.1_full 的索引優化邏輯，額外縮減為財務單位指定的 27 欄位。 | 同上一列說明。PQ 另有保留未來增減欄位的可擴充性。 |
