# S06 Excel實作 — 逐項評分細則與檢查方法

本文件補充 `assets/01_template/S06_excel_scoring_criteria_v1.xlsx` 的文字敘述，記錄「怎麼從
.xlsx 檔案裡技術性地驗證每一小項」，以及批改過程中已經遇過的實際案例（正確
做法 / 常見錯誤）。搭配 `engine/extract_submission.py` 的輸出一起讀。

**工作表名稱**：【薪資】【成績】【車輛銷售】【武將能力】四個工作表名稱允許加
前後綴（例如「1.薪資」「成績_作答」「車輛銷售(完成)」）。對應規則：名稱完全
相同（忽略前後空白）的優先；否則取唯一一個名稱含該文字的工作表。實際對應
寫在 `sheet_names`（例如 `{"薪資": "1.薪資"}`），有前後綴時評分結果會附一條
提醒。多個工作表都含同一文字時列在 `ambiguous_sheets`、不自動挑選，該大題
以0分計並提醒人工確認；完全找不到則列在 `missing_sheets`。原始資料比對
（3.x／4.x）時，學生端用對應到的工作表，題目檔端仍用原名稱。

## 考題1. 薪資（樞紐分析）

**判斷有無樞紐表（1.1 的前提）**：用 `engine/extract_submission.py` 的
`pivot_薪資` 欄位判斷。樞紐表可以放在【薪資】活頁，也可以放在其他活頁
（Excel 插入樞紐表預設會開新活頁，例如「1.男女平均薪資」），但來源必須是
【薪資】活頁的資料（`worksheetSource` 的 `sheet` 是薪資，或來源表格定義在
薪資活頁上）。實際所在活頁與範圍寫在 `host_sheet` / `location`。
**【考題】活頁上的範例樞紐表一律排除**（名稱含「考題」的活頁不找；那個範例
的來源也是外部活頁簿，同樣會被排除）。先找【薪資】活頁本身，再找其他活頁，
取第一個符合的。
若 `pivot_薪資` 為 `null`，代表沒有以薪資資料為來源的樞紐表 → **1.1~1.5 全部 0 分**
（不用再檢查其他小項）。

**1.2 欄列標籤**（10分＝欄5＋列5）：看 `col_visible_labels` / `row_visible_labels`。
- 列標籤（row）必須同時有「男」「女」→ 否則列這5分給0。
- 欄標籤（col）必須只留下「業務」一項 → 才給欄這5分。只要不是只留下「業務」
  （包括同時列出業務、會計、門市三個部門、沒有欄標籤、或完全不是這三個部門），
  欄這5分都給0。舊版【折衷微調】「三個部門全列也給滿分」已從評閱標準刪除。

**1.3 彙總方式**：看 `data_fields[0].subtotal`。`"average"` 給滿分；
`"sum"` 給一半（Excel 在加總時常省略 subtotal 屬性，`null` 也視為加總）；其他給0。

**1.4 貨幣格式**：**不要只看 pivotField 的 numFmtId**——很多檔案
`applyNumberFormats="0"`，代表 pivot 自己的格式設定不會套用，實際顯示格式
要看 pivot 輸出區塊（`location` 範圍）儲存格本身的 `number_format`（`value_number_formats`
欄位）。含 `"$"` 字樣 → 滿分；「通用格式」或純數值（如 `#,##0`）→ 半分；
其他 → 0分。

**1.5 額外加分（來源為表格）**：看 `source_is_named_table`。若
`source_name_or_range` 是一個名稱（如 `"salary"`）而不是像
`"薪資!$A$1:$J$13"` 這種含 `$`/`:` 的儲存格範圍字串，代表樞紐表來源已設為
Excel表格 → 給滿額外加分（6分）。

## 考題2. 成績

用 `grades_sheet_info`（腳本 `成績` 欄位）逐項核對：

- **2.1 凍結窗格**（4分）：`freeze_panes == "B3"` → 滿分。如果只固定列
  或只固定欄（例如 `"A3"` 或 `"B1"`），各給一半。
- **2.2 合併後置中**（4分＝設定2＋標題2，兩部分各自計分）：
  `a1_merge_and_center` 為真（A1:G1 合併儲存格，且 A1 水平對齊為置中）→ 設定2分。
  合併範圍不是剛好 A1:G1（`a1_merged_range` 例如 `"A1:H1"`）、只合併沒置中、
  或只設「跨欄置中」對齊而沒合併（`a1_horizontal == "centerContinuous"`、
  `a1_merged_range` 為 `null`），設定這2分都給0。`header_text_preserved`
  （A1文字是「經濟甲班 期中考成績表」）→ 標題2分，不論設定是否正確。
- **2.3 公式與範圍**（9分）：`g3_g15_average_formulas_ok`（G3:G15 都用
  AVERAGE）給一半；`row_avg_formulas_ok` 且
  `row_avg_integer_format`（班平均列 B:F 用 AVERAGE 且顯示為整數格式）
  給另一半。**注意**：先用 `avg_row_index` 確認「班平均」是哪一列，不要
  預設一定是第16列。班平均列用 `SUBTOTAL(101,…)` 取代 AVERAGE
  （`row_avg_uses_subtotal` 為真）→ 班平均這一半給0。
- **2.4 排序與篩選**（10分＝排序5+篩選5，依【微調】版本）：
  `sort_conditions` 有個人平均（G欄）由大到小 → 排序5分；`filter_conditions`
  有個人平均欄（`col_id == "6"`）的數字篩選 val=70，operator 為 `greaterThan`
  （>70）或 `greaterThanOrEqual`（≥70）都算 → 篩選5分。用勾選數值清單篩選
  （`operator == "values"`）或篩選在其他欄位，都不算「數字篩選 > 70」，
  篩選給0。注意 `filter_gt70_applied` 只認 `greaterThan`，判斷時以
  `filter_conditions` 為準。兩者互相獨立，
  常見錯誤是「只排序、忘記篩選」（`hidden_rows` 應該是 `[11,12,13,14,15]`
  這樣的 5 列被隱藏；如果 `hidden_rows` 是空的，通常代表篩選沒有真的套用）。
- **2.5 框線**（3分）：`borders_complete` 為真才給分，否則0分（依標準沒有
  半分選項，此項是全有全無）。
- **2.6 額外加分（G16留空）**（3分）：G16 不可填入任何 Excel 公式、數值或
  文字，`g_avg_row_cell.is_empty` 為真才給分。曾出現的錯誤案例：學生把「個人
  平均」那欄也往下拉出 `=AVERAGE(G3:G15)`，這樣 G16 就有公式了，不能給這項
  加分（但不影響 2.3 的分數，因為 2.3 只看 B:F 欄）。

## 考題3. 車輛銷售（動態直條圖）與 考題4. 武將能力（動態雷達圖）

兩題判斷邏輯相同，差別只在圖表類型與座標軸/圖例應顯示的內容。

**第一步：判斷原始資料是否被更動（極重要，會讓整大題歸零）**

用 `--question` 參數提供原始題目檔（`assets/01_template/S06_excel_question_v1.xlsx`），
腳本會輸出 `車輛銷售_raw_data_check` / `武將能力_raw_data_check`，比較
A欄類別（廠牌／武將能力屬性）與第2列標頭（月份／武將姓名）是否與原始題目
完全一致。**只要有任何一格不同（`unchanged: false`），該大題（3.1~3.4 或
4.1~4.3）全部給0分**，不用再檢查圖表細節。已知案例：學生把「一月/二月/
三月」改成「十一月/十二月/十三月」，這樣即使圖表技術上仍是動態的，也要
整題歸零。

比對時會先去掉前後空白再比較：題目檔武將能力 D2「程遠志」本身帶一個結尾 Tab
字元，學生把這個 Tab 刪掉**不算**更動原始資料（4.1 的例外），不會讓考題4歸零。

**多張圖表**：同一活頁有多張圖時（`chart_count > 1`），只評分「動態且類型正確」
的那一張（車輛銷售找 barChart、武將能力找 radarChart），其餘忽略；都不符合時
退回評第一張（通常就會因類型或非動態而整大題0分）。評分結果會附一條提醒。

**第二步：確認圖表是動態的**

`is_dynamic` 為真（`c:numRef`/`c:strRef` 存在，代表公式參照儲存格而非
寫死數值）。若 `literal_only` 為真（`numLit`/`strLit`，貼上固定數值），
該大題（3.x 或 4.x）全部0分。

**第三步：確認圖表類型（也會讓整大題歸零）**

- 考題3 只限長條圖、直條圖、直方圖：`chart_type == "barChart"`（直條圖、橫條圖都是
  barChart，`bar_dir` 為 `col`／`bar`）。立體群組直條圖（`bar3DChart`，`is_3d` 為真）
  也回報為 `barChart`，一樣給分。
- 考題4 只限雷達圖：`chart_type == "radarChart"`。
- 其他圖表類型（折線圖、圓餅圖…）→ **該大題（3.1~3.4 或 4.1~4.3）全部0分**。
- 直方圖是 Excel 2016 以後的新式圖表（chartEx），XML 格式不同，腳本不解析，只在
  `chartex_count` 計數。【車輛銷售】只有這類圖表時，考題3暫給0分並標成需人工確認；
  【武將能力】不接受直方圖，直接0分。

**3.1 / 4.1 作答狀態**（各5分）：通過上面三步（資料未被更動、圖表為動態、圖表類型
正確）→ 滿分。

**3.2 座標軸設定**（15分，三等分）：
- 類別（`categories`）需恰好是 `["福特","賓士","裕隆","三菱"]`（順序不拘，
  但四個都要有、不能多也不能少）→ 5分。**常見錯誤**：把類別軸設成月份
  （一月/二月/三月），把廠牌放到圖例——這是把兩個維度對調了，類別軸這5分
  直接是0。
- `y_max == "2000"` 且 `y_major_unit == "500"` 兩者都對才給5分（其中一個
  錯就是0，不是各半）。
- `gridlines_none` 為真 → 5分。

**3.3 圖例設定**（5分）：`series_names` 需恰好是
`["一月","二月","三月"]`（順序不拘），少一個或多一個都是0分（此項沒有
半分）。

**3.4 額外加分**（9分，三項各3）：
- `has_data_labels` → +3（注意題目特別註明：如果學生用的是「資料表
  (Data Table)」而不是逐點資料標籤，兩者要區分清楚，`dLbls` 的
  `showVal` 才算一般資料標籤；資料表功能是另一個 XML 節點
  `plotArea/dTable`，腳本以 `has_data_table` 回報；`has_data_labels: false`
  但 `has_data_table: true` 時，打開 chart XML 人工確認）。
- `has_chart_title` → +3。
- `has_x_axis_title` 且 `has_y_axis_title`（兩者都要有才算，因為原題目
  要求「縱軸的數量」和「橫軸的廠牌」都要標）→ +3。

**4.2 座標設定**（10分，拆解5+5）：
- 類別軸（`categories`）需恰好是
  `["統帥","武力","智力","政治","魅力"]` → 5分（全對才給，任一缺漏0分）。
- 圖例（`series_names`）需恰好是 `["趙雲","周瑜","程遠志","劉禪"]` → 5分
  （原始資料裡「程遠志」字串可能帶有一個 tab 字元 `\t`，比對時先
  `.strip()` 再比較，避免因為看不見的空白字元誤判；同一個 Tab 在原始資料
  檢查的處理見上方 4.1 的例外）。

**4.3 額外加分**（6分，兩項各3）：
- `has_chart_title` → +3。
- 使用含資料點標記的雷達圖：檢查 `marker_symbols`，如果全部是
  `"none"` 代表雖然 `radarStyle` 可能設為 `"marker"`，但每個資料點的
  `c:symbol` 都是 none，等於沒有真的顯示標記 → 不給分。要看到
  `marker_symbols` 出現 `"circle"`／`"diamond"` 等非 none 的值才給分。
